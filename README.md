# 📍 Buscador de CEP

Aplicativo desenvolvido em **React Native + Expo** como atividade acadêmica para a Faculdade Senac Pernambuco. Ele consome dados das APIs públicas **ViaCEP** e **Nominatim (OpenStreetMap)** para exibir endereços, centralizar o mapa, permitir geocodificação reversa por toque, aplicar máscara de CEP e gerenciar um histórico de buscas persistente localmente.

## 🚀 Tecnologias Utilizadas
- React Native / Expo
- React Native Maps
- AsyncStorage (Persistência de histórico)
- API ViaCEP & Nominatim (OpenStreetMap)

## ⚙️ Como executar o projeto

Clone o repositório:
   ```bash
   git clone https://github.com/gaahtenorio/buscador-de-cep.git
   ```

1. Entre na pasta do projeto e instale as dependências:
  ```bash
   cd buscador-de-cep
   npm install
  ```

2. Inicie o projeto:
  ```bash
  npx expo start
  ```
3. Escaneie o QR Code com o aplicativo Expo Go no seu celular ou abra em um emulador Android/iOS.
